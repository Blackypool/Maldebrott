Была создана программа на базе библиотеки sfml для проверки корректного построения множества (и чтобы позалипать).
*Далее измерения проводились исключительно на основном цикле вычисления точек.*

Без оптимизаций скорость выполнения составила в среднем за 500 запусков (компиляцией через clang++ с включенной оптимизацией -О3) 127.7 ms, что быстрее в 2.80x раз чем без оптимизации -О3.

**Для достижения цели использовалось две техники:**
1 - обработка сразу 4 пискселей. Мы подсказываем компилятору, что надо бы использовать векторные операции для обработки массива пискселей. Такая оптимизация при компиляции через <clang++ -О3> дает время выполнения цикла в среднем 35.7 ms.
2 - использование интринсиков (команд, которые напрямую говорят процессору какие действия с чем выполнять). Время выполнения с такими же флагами составило в среднем
